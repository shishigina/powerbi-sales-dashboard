# Аналитика продаж (Power BI Pet Project)

## О проекте
Данный проект выполнен в рамках тестового задания от компании "Data Sfera". Целью было провести нормализацию исходных данных, построить модель данных, рассчитать бизнес-метрики и создать интерактивный дашборд для руководства.

## Бизнес-задача
* Нормализовать данные из исходного источника (Google Sheets).
* Привести типы данных к корректным.
* Создать собственный календарь (СПР-даты заказа не содержали всех дат).
* Рассчитать ключевые метрики: Выручка, Прибыль, Средний чек, Рентабельность, Затраты на логистику.
* Провести ABC-анализ номенклатуры.
* Визуализировать динамику продаж, распределение по менеджерам и географии.

## 🛠 Инструменты
* **Power BI Desktop** (ETL, Моделирование данных, DAX, Визуализация)
* **Power Query** (Очистка и трансформация данных)
* **Google Sheets** (Исходный источник данных)

## 📊 Результаты и инсайты
* Общая выручка за период составила **1,10 млн**, чистая прибыль — **253,78 тыс.**
* Рентабельность продаж находится на уровне **23%**.
* Наибольшую долю в выручке приносят товары класса А (по ABC-анализу), при этом наблюдается сезонный пик продаж в марте.


## Как запустить проект
1. Скачайте файл `Dashboard/Аналитика_продаж.pbix` из этого репозитория.
2. Откройте его в программе **Power BI Desktop**.
3. Если данные не обновились автоматически, нажмите "Обновить" (Refresh) в ленте главного меню (потребуется доступ к исходному Google Sheets).
